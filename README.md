# CLI ATM & Banking System 🏧

A simple command-line interface (CLI) banking application built in C++. This project was created as a beginner exercise to practice core programming fundamentals.

## Features-
* **Check Balance:** View your current account balance anytime.
* **Deposit Funds:** Add money to your account dynamically.
* **Withdraw Funds:** Secure withdrawal feature that checks for insufficient funds before completing the transaction.
* **Interactive Menu:** Uses a continuous loop to keep the system running until you choose to exit.

## C++ Concepts Practiced-
* `do-while` loops for continuous menu navigation
* `if-else` conditional statements for option handling and validation logic
* Variables and basic state management
* Standard Input/Output (`std::cin` and `std::cout`)
